# 错误详情弹窗修复

## 现象

工作区里的失败卡片被点击后，没有弹出完整的错误详情，而是整张卡片变成一块浅色空白方块。

## 根因

`ErrorDetailsModal` 直接 `return (<div className="modal open">…)`，弹窗被渲染在 `.art-card` **内部**。

卡片自身有 `transform`（`card-in` 入场动画 + `:hover` 的 `translateY(-4px) scale(1.015)`）和 `overflow: hidden`：

- `transform` 会让卡片成为 fixed 定位的包含块，`.modal` 的 `inset: 0` 于是相对卡片而不是视口计算；
- `overflow: hidden` 再把超出卡片的部分裁掉。

弹窗因此被压成卡片大小（实测 174×174，面板 146×838），内容被裁，只剩一层浅色底。

项目里其他弹窗（`PreviewModal`、`SettingsModal`、`HistoryPromptsModal`、`MaskEditor`、`ReferencePreviewModal`、`PromptTemplateEditorModal`）都已用 `createPortal(..., document.body)`，只有 `ErrorDetailsModal` 漏了。

## 修复

1. `src/renderer/src/components/workspace/ErrorDetailsModal.tsx`：改用 `createPortal(content, document.body)`，弹窗脱离卡片裁剪。
2. `src/renderer/src/styles.css`：`error-details-*` 系列把硬编码的浅色（`#edf6f1`、`rgba(237,246,241,…)`）换成语义变量（`--ink`、`--ink-soft`、`--muted`、`--line`、`--surface-2`），修正深色主题下白底白字。

## 验证

- `tsc --noEmit` 通过，`electron-vite build` 通过。
- CDP 实测：修复前弹窗尺寸 174×174、父节点 `.art-card`；修复后 1424×1001、父节点 `document.body`。
- 浅色 / 深色主题分别截图确认，「请求参数」「响应体」「原始错误详情」三块内容完整可读。
- ESC 键正常关闭。
